# ART VPN

Windows-клиент совместимых VPN-подписок: фоновая служба, выбор проверенного
канала, отдельные маршруты для российских сайтов и локальной сети, резерв через
локальный прокси Throne/HAPP. Это клиент, а не бесплатная VPN-подписка.

Пользовательская версия называется **ART VPN 1.0**; этот снимок исходников
соответствует изменениям кандидата **1.0.19**. Публикация исходников сама по себе
не означает выпуск нового установщика, одобрение подписи или полную приёмку.

## Как работает

- После установки пользователь вставляет совместимую HTTPS-подписку и нажимает
  «Сохранить и подключить». Проверенный канал подключается в режиме «Авто».
- Пока новый канал не подтверждён, прежнее подключение сохраняется.
- Throne/HAPP используются как внешний локальный **прокси**, если он доступен.
  Полная автоматическая передача управления чужим TUN-клиентом не заявляется.
- При необходимости повторного запуска Codex приложение даёт рекомендацию;
  оно не должно принудительно завершать произвольные пользовательские приложения.
- Рекомендация Quattro содержит реферальную ссылку автора. Это необязательная
  рекомендация, не гарантия качества или доступности и не условие установки.
