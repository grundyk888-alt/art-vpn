# ART VPN 1.0

Windows-клиент VPN-подписок с автоматическим выбором подходящего канала для
ChatGPT и Codex, фоновым поиском резервов и отдельными маршрутами для российских
сайтов и локальной сети. Нужна собственная совместимая подписка: приложение не
предоставляет бесплатный VPN-сервис.

**Текущая сборка: 1.0.40.** Публичное название продукта — ART VPN 1.0;
внутренние номера позволяют различать обновления.

## Скачать для Windows x64

- **[Скачать с GitHub — последний выпуск](https://github.com/grundyk888-alt/art-vpn/releases/latest)**
- [Скачать с основного сайта ArtFitness](https://artfitness.ru/vpn/)

В выпуске выбирайте `ART-VPN-1.0.40-win-x64.zip`, распакуйте архив и запустите
`ART-VPN-Setup.exe`. Архивы `Source code` предназначены для разработчиков.
На GitHub и ArtFitness публикуется один и тот же проверенный установочный ZIP.

Установщик пока не имеет доверенной подписи Windows: возможно предупреждение
SmartScreen. Сверяйте источник и SHA-256 из выпуска. Не отключайте защиту Windows
и не устанавливайте неизвестные корневые сертификаты.

## Начать пользоваться

1. В первом окне установки вставьте свою HTTPS-ссылку подписки и нажмите «Установить».
2. Установщик проверит систему, покажет этапы работы и попробует подключить первый
   подходящий канал в режиме «Авто». При проблеме откроется диагностика.
3. После подключения более глубокая проверка каналов и поиск резервов продолжатся
   в фоне. Готовность резервов может появиться позже первого подключения.

Режим «Авто» использует ART VPN как основной канал и доступный внешний резерв при
подтверждённом сбое. Кнопки HAPP/Throne — явный ручной выбор; вернуться к ART VPN
можно кнопкой «Авто» или «ART VPN». Поддержка передачи HAPP TUN проверялась отдельно;
совместимость с любым сторонним VPN и бесшовное сохранение всех соединений не гарантируются.

Если запущен Codex, установщик может предложить его перезапуск с отсчётом 10 секунд
и кнопкой отмены. Перед установкой сохраните работу. Поиск чужих подписок удалён:
ссылку нужно вставить самостоятельно.

Необязательная рекомендация Quattro открывается только по нажатию и не является
условием установки. Автор может получать вознаграждение за переходы/регистрации.
