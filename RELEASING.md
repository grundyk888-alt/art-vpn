# Выпуск: ArtFitness и GitHub

Оба канала должны получать одну актуальную принятую сборку. Публичное название —
ART VPN 1.0, но каждый выпуск имеет уникальный внутренний номер и тег `v<номер>`.
Не заменяйте файлы под уже опубликованным тегом другой сборкой.

1. Завершить согласованную приёмку, записать изменения, проверки и ограничения.
2. Проверить отсутствие секретов в исходниках/пакете; сохранить лицензии и
   соответствующие исходники всех распространяемых компонентов.
3. Обновить исходники GitHub, README, CHANGELOG и TESTING. Проверить CI нужного коммита.
4. Создать GitHub Release с тегом внутренней версии и точным установочным ZIP,
   соответствующими исходниками и SHA256SUMS. Указать статус подписи Windows.
5. Опубликовать тот же установочный ZIP на ArtFitness и штатный подписанный feed.
   Подпись feed не является Authenticode. Закрытые ключи никогда не публикуются.
6. Проверить публичное скачивание, размеры и хеши на обоих каналах и кнопку сайта.
   Лишь после проверки замены удалять старые файлы сайта в согласованном объёме.

Текущая сборка 1.0.40 была сначала принята и опубликована на сайте; GitHub добавлен
как дополнительное место скачивания. Основной сайт остаётся https://artfitness.ru/vpn/.
Новые сборки не публикуются без проверки автоматически по каждому коммиту.
